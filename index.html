Part 1 – Shortest Distance to a Function

In this part, I am finding the shortest distance from different points to a parabola function. The function I am using is y = x² + 5.

The points I am testing are (0,0), (-4,0), (-8,0), (2,0), and (6,0).

1.1 Analytical Method

I started by using the distance formula between the point and a point on the parabola. Then I squared the distance formula to make the calculation easier. After that, I differentiated the squared distance function. I set the derivative equal to zero and substituted the different points to find the closest point on the parabola. Finally, I used the closest x-value to calculate the actual distance.

1.2 Newton-Raphson Method

For the Newton-Raphson method, I used the first and second derivatives to calculate an updated value of x. I started with an initial guess and repeatedly substituted each new x-value back into the formula. I stopped when the difference between two consecutive values became very small. The final x-value was then used to calculate the shortest distance.

1.3 Newton-Raphson Python Results

I created a Python program to apply Newton-Raphson to all five required points. The program takes the point coordinates and an initial guess, performs the iterations, and prints the closest x-value, corresponding y-value and shortest distance.

1.4 Golden Section Search

For Golden Section Search, I started by selecting a search interval and calculating two points inside it using the golden ratio. I compared the squared distances at these points and removed the side with the larger value. This progressively reduced the interval until it became very small. Unlike Newton-Raphson, this method does not require derivatives.

1.6 Non-Polynomial Function Test

To check that the numerical methods were not limited to polynomial functions, I tested them using the exponential function y = ex. Both Newton-Raphson and Golden Section Search converged to almost the same closest point and distance.

1.7 Intermediate-Step Plot

The intermediate-step plots show how the numerical methods approach the final solution. For Newton-Raphson, successive estimates move toward the closest point on the curve.

1.8 Part 1 Results Summary

Part 2 – Fitting a Function

In this part, I fitted both a straight line and a parabola to the given data points. The aim was to find the parameters that minimise the Mean Squared Error (MSE). A smaller MSE means that the fitted function is closer to the original data.

2.1 Mean Squared Error and Line Fitting

I first fitted a straight line using y = mx + b. For each point, I calculated the predicted value and compared it with the actual value. The errors were squared and averaged to form the MSE.

2.2 Line – Analytical Solution

I wrote the MSE as a function of m and b and calculated the partial derivatives with respect to both parameters. Setting both derivatives equal to zero gave the values that minimise the error.

Final line: y = 2.3x - 0.2
MSE: 0.575

2.3 Line – Numerical Python Method

For the numerical solution, I used Newton-Raphson to update m and b one at a time. The process was repeated until the changes became very small. The final numerical values agreed with the analytical result.

2.4 Line – Intermediate-Step Plot

The lines move progressively toward the final fitted solution.

2.5 Parabola – Analytical Solution

For the parabola, I used y = ax² + bx + c. I created the MSE using the prediction errors and calculated the partial derivatives with respect to a, b and c. Solving the three equations gave the final parabola parameters.

a = 0.75
b = 0.05
c = 0.55

Final parabola: y = 0.75x² + 0.05x + 0.55

2.6 Parabola – MSE

I substituted the x-values into the fitted parabola, calculated the errors, squared them and averaged them.

Parabola MSE = 0.0125

2.7 Parabola – Numerical Python Method

I used Newton-Raphson to update a, b and c one at a time. The iterations continued until the changes in all three parameters became very small. The numerical result was consistent with the analytical solution.
